# 💻 Konark Computers - Rajkot

Official website for **Konark Computers**, offering fast and reliable computer repair, laptop servicing, networking, and IT consulting services in Rajkot, Gujarat, India.

🌐 **Live Site**: [konarkcomputers.vercel.app](https://konarkcomputers.vercel.app)

---

## 🌟 Key Features

- 📱 **Fully Responsive Layout**: Built with HTML5, CSS3, Bootstrap, and jQuery for seamless browsing on mobile, tablet, and desktop devices.
- 🛠️ **Service & Product Showcase**: Displays laptop/desktop repair services, networking solutions, and computer accessories.
- 📩 **Contact Form**: Powered by [FormSubmit.co](https://formsubmit.co) — sends inquiries directly to email, no backend needed.
- ⚡ **100% Static Site**: Pure HTML/CSS/JS — no PHP, no database, lightning-fast page loads.
- ☁️ **Vercel Hosted**: Deployed as a static site on Vercel with zero server maintenance.

## 🚀 Deployment

### Vercel (Current)

The site auto-deploys from the `main` branch. Any push to `main` triggers a new build.

### Local Development

Simply open any `.html` file in a browser, or use a local server:

```bash
npx serve public_html
```
